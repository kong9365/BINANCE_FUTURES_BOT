# 새 가설 3종 검증 보고서 (초보자용)

> **무엇**: 운영자 지시로 "전략 사냥"을 재개해 새 가설 3종을 **현재와 동일한 사전확정 게이트**로 검증.
> **데이터**: 1d(일봉) 52종목, 2022-05~2026-05. 1차 OOS = 2023-05-27 이후(워밍업 365일), 2차 신선 OOS = 2024-11-24 이후.
> **결론 미리**: **3종 모두 통과 실패.** tsmom_ens는 표본 충분(n=331)한데 **FAIL**, faber 2종은 표본부족 + *집중 착시* + 신선구간 손실, mean_rev는 **CostGuard가 구조적으로 거부**(거래 0). → **실거래 HOLD 유지.**

---

## ⚠️ 0. 가장 먼저 — 이 보고서를 오해하지 않기

1. **3개를 *동시에* 검증했다.** 여러 개를 한 번에 돌리면 *우연히* 하나가 게이트를 통과할 확률이 올라간다(다중검정). 그래서 **게이트 PASS = "1차 흥미로움"일 뿐, "검증됨"이 절대 아니다.**
2. **PASS가 나와도** ① 펀딩 포함 재검증(§5 F1) + ② **2차 신선 구간**에서 동일 게이트 재확인 — *둘 다* 통과해야 "잠정 유효"이고, **그래도 라이브가 아니다(HOLD).** 이번엔 **PASS 자체가 없었다.**
3. **FAIL이면 폐기한다.** 통과시키려 파라미터를 만지거나(튜닝) 필터를 추가하지 않는다. 이 보고서의 목적은 "통과하는 전략"이 아니라 **정직한 판정**이다.

## 1. 검증 방법 (초보 설명)

- **사전확정 게이트**(검증 *전에* 고정, 통과 후 손대지 않음): **n≥200**(미만이면 통계적 판정불가=INSUFFICIENT) → 이후 **gross_R>cost_R**(비용 전부터 +) · **PF≥1.2** · **Sharpe≥1.0** · **최악3개월MDD<20%** · **코인별 양수비율>55%**.
- **1차 / 2차 신선**: 워밍업(200일 이동평균 계산용 365일) 이후 전체를 "1차"로, 그 구간을 다시 절반으로 갈라 **후반(최근=신선)** 을 "2차"로 *같은 게이트* 재평가. 견고한 엣지라면 둘 다 통과해야 한다.
- **점 ⓐ (정직 고지)**: 여기서 cutoff는 *지표 워밍업 경계*일 뿐 IS/OOS 적합분할이 아니다(파라미터를 데이터에 맞춘 게 0이라 그렇다). 과최적화 위험은 *전략을 여러 개 고른 것*에서 오며, 그 방어가 위 2차 신선 재확인이다.
- **판정 체결모델 = post_only**(실제 라이브식 지정가). maker_open은 비교용(1d에선 거의 동일).
- 비용 반영, 룩어헤드 0(엔진이 ts 이전 마감봉만 사용), 보호종목 무관, 동결 검증 하네스 그대로 재사용.

**가설 셋(고정 단일 규칙):**
- **faber**: 종가 > 200일 이동평균(SMA200)이면 매수 / 미만이면 매도. **청산 = 종가가 SMA200을 반대로 교차**(저회전, 수개월 보유 → 비용을 정면 공략). 재난 손절 3·ATR.
- **faber_long_only**: 위의 매수 전용.
- **tsmom_ens**: 1·3·6개월 수익률 *부호 합*으로 방향(추세추종 앙상블). 약 1개월 보유 후 재평가.
- **mean_rev**: SMA200 위(상승추세)에서 RSI(2)<5(단기 과매도) 매수 / 대칭 매도. 고정 익절 1·ATR + 손절 2·ATR.

## 3. 가설별 상세 + 초보 해석

### 3-1. faber (저회전 추세, 롱+숏) — "표본부족 + 최근 구간 손실"
- 1차: 116거래, PF 1.45, gross +0.208R. 겉보기엔 +지만 **거래수 116<200**(저회전이라 거래가 적음) → 통계 판정불가.
- **신선(2차)에서 음전환**: 최근 절반 구간 gross **−0.137R**(Sharpe −0.96). 즉 *최근엔 안 통했다.*
- **집중·시간감쇠**: 1000PEPE 한 종목이 +27R로 결과를 끌어올림(코인양수 46%<55%). 연도별 2023 +1.09 → 2025 **−0.17** → 감쇠.
- 청산 분포: MA교차 89 / 손절 17 / 데이터끝 10 (MA-교차 청산 메커니즘 정상 작동 확인).
- **해석**: 저회전이라 표본이 모자라고, 최근 구간은 손실이며, 이익은 한 코인 운에 쏠림 → **엣지 근거 없음.**

### 3-2. faber_long_only (매수 전용) — "가장 좋아 보이지만 SOL·TRX 쏠림 착시"
- 1차: 120거래, PF **2.30**, gross +0.508R, Sharpe 0.72 — 4종 중 표면 최고.
- **그러나** SOLUSDT +40R, TRXUSDT +24.6R **두 종목이 전부**(코인양수 **43%**<55%). 이는 과거 CSM 전략을 떨어뜨린 *집중 착시*와 똑같은 모습.
- **신선(2차) 음전환**: 최근 절반 gross **−0.067R**. 연도별 2023 +2.93 → 2025 **−0.28**.
- **해석**: 높은 PF는 *몇 코인의 큰 상승장 운*. 표본부족 + 신선구간 손실 + 분산 실패 → **신뢰 불가.**

### 3-3. tsmom_ens (추세추종 앙상블) — "표본 충분(n=331), 그래서 결정적 FAIL"
- 1차: **331거래**(판정 가능!), PF 1.17, gross +0.076R, Sharpe 0.59, 코인양수 55%.
- **FAIL 사유**: PF 1.17<**1.2**, Sharpe 0.59<**1.0**, 코인양수 55%(>55% 아님). gross는 비용 전 살짝 +지만 게이트 미달.
- 청산: 시간스톱 185 / 손절 98 / 익절 38 (월 보유 설계대로 시간스톱 지배). 연도별 +0.10→+0.08→**−0.02**(감쇠).
- **해석**: 표본이 충분한데 게이트를 못 넘음 = **명확한 FAIL.** 미세한 +0.076R는 비용·변동성을 이기지 못한다.

### 3-4. mean_rev (단기 평균회귀) — "CostGuard가 진입 자체를 거부 (거래 0)"
- 거래 **0건.** 단, 신호 조건(SMA200 위 + RSI(2)<5)은 진단상 **롱 479일 + 숏 903일** 실제 발생 → "신호가 드물어서"가 **아니다.**
- **근본 원인 = CostGuard(비용 차감 기대값 게이트, TIER-1)**: 이 설정의 손익비가 **익절 1·ATR / 손절 2·ATR = 0.5:1**이라, +기대값이 되려면 **승률 66.7% 초과**가 필요. 백테스트엔 이 셋업의 실측 승률이 없어 보수적 기본값 **45%**를 쓰므로 **모든 신호가 −기대값으로 거부**됨.
- **해석**: mean_rev는 *봇의 비용 게이트 자체를 통과 못 하는 구조*(보상<위험). 이는 게이트가 *제대로 작동*한다는 증거이기도 하다. **규칙대로 폐기**(승률을 높이려 익절/손절을 튜닝하지 않음 — 그건 사후 끼워맞추기).

## 4. ★ 가장 중요한 교훈

1. **"표면 PF가 높다"에 속지 말 것.** faber_long_only PF 2.30은 SOL·TRX 2종목 쏠림(코인양수 43%)이고, **최근(신선) 구간에선 손실**이었다. 과거 모든 실패와 같은 패턴(집중 착시 + 시간감쇠).
2. **표본이 충분하면 결론은 깔끔하다.** tsmom_ens는 n=331로 판정 가능 → **FAIL**(게이트 미달). 작은 표본의 "흥미로움"과 달리 이건 확정.
3. **게이트는 작동한다.** mean_rev는 백테스트를 *돌리기도 전에* CostGuard가 −EV로 막았다. 비용 게이트가 나쁜 손익비를 사전에 차단한 것.
4. **2차 신선 OOS의 가치**: faber 2종 모두 1차는 +였지만 **신선 구간에서 −로 뒤집힘** → "최근에 통하는가"를 보면 환상이 드러난다.

## 5. 충실성 한계 (정직 고지)

- **F1 (펀딩=0)**: 검증 캐시에 펀딩비가 없어 cost_R = 수수료+슬리피지만 반영. 다주 보유 롱(faber/tsmom)은 **실제 펀딩비가 빠져 비용이 과소**계상 → funding=0은 롱에 *유리*. 따라서 **FAIL/미달은 더 견고**(펀딩 넣으면 더 나빠짐), 가령 PASS가 나왔어도 펀딩 재검증 전까진 잠정. (이번엔 PASS 없음.)
- **D2 (Sharpe 부정확)**: 검증 하네스의 Sharpe는 거래 사이 자본을 평탄하게 보므로 **저회전 faber에는 신뢰도 낮음**(동결 게이트는 건드리지 않음). faber 판정은 gross_R>cost_R·PF·MDD·코인양수를 우선으로 읽었다.
- **D1 (R 스케일 차이)**: faber/tsmom(손절 3·ATR)과 mean_rev(2·ATR)는 손절폭이 달라 **거래당 R 크기를 전략끼리 직접 비교 금지**(gross_R>cost_R 부호 판정은 유효).
- **R1 (HIGH_VOL 차단)**: 변동성 극단 구간엔 *모든 전략* 진입이 차단된다(기존 동결 동작, 신규도 동일 적용 — 게이트 완화 아님).

## 6. 용어 사전 (초보자)
- **n(거래수)**: 표본. **200 미만 = 통계 판정불가(INSUFFICIENT).**
- **PF(Profit Factor)**: 번 돈÷잃은 돈. ≥1.2 합격선.
- **gross_R / cost_R / net_R**: 거래당 *비용 전 / 비용 / 비용 후* 손익을 "건 위험(R)의 배수"로. gross_R이 −면 비용 전부터 손실.
- **Sharpe**: 위험 대비 수익(높을수록 좋음, ≥1.0 합격선). *저회전 전략엔 부정확*(D2).
- **코인양수(cross-pair+)**: 이익 낸 코인 비율. >55%여야 한 코인 운이 아님.
- **CostGuard**: 진입 전 *비용 차감 기대값*이 +인지 검사하는 게이트. −면 진입 거부.
- **1차/2차 신선**: 전체 OOS / 그 후반(최근) 구간. 견고하면 둘 다 통과해야.

## 7. 결론
1. **통과(승급) 0건.** tsmom_ens = FAIL(n=331 확정), faber 2종 = 표본부족+집중+신선 손실, mean_rev = CostGuard 거부(거래 0).
2. **방법 일관성**: 파라미터 무수정(튜닝 0), 비용 반영, 룩어헤드 0, 동결 게이트·하네스 재사용, FAIL→폐기.
3. **이전 결과와 일관**: Phase C / Track A·B / SMC / 캐리와 동일하게 **비용·집중·노이즈를 이기는 엣지는 발견되지 않음.**
4. **실거래?** → **HOLD 유지.** PASS가 나왔어도 2차 신선 OOS + 펀딩 재검증 전까진 라이브 아님. 이번엔 PASS 자체가 없다.
