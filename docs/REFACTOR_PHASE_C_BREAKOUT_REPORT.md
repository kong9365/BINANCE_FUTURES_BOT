## 0. 판정 (사전확정 게이트 — post_only 현실 체결 기준)

| 게이트 | 기준 | post_only 실측 | |
|---|---|---|---|
| 총 OOS 거래수 | ≥ 200 | **86** | ❌ |
| OOS Sharpe | ≥ 1.0 | **−1.27** | ❌ |
| Net PF | ≥ 1.2 | **0.52** | ❌ |
| 최악 3mo MDD | < 20% | 5.4% | ✅ |
| 거래당 gross > 비용 | gross_R > cost_R | **−0.242 ≤ 0.015** | ❌ |

→ **공식 판정 = 표본부족(판정불가)**: n=86 < 200. 운영자 사전확정 규칙상 *결론이 아니라 판정 불가*이며, **답은 파라미터 튜닝이 아니라 데이터 확장(코인↑·기간↑·인트라데이 TF 백필).** 파라미터는 손대지 않았다.

## 1. ★ 그러나 — 방향 증거는 강하다 (결론 아님, 보고만)

n<200이라 *공식 판정*은 불가지만, 86건의 방향 신호는 명확하다:
- **gross_R = −0.242 (비용 *차감 전* 음수).** PF 0.52, Sharpe −1.27.
- **cost_R = 0.015 (작음).** 즉 **비용이 문제가 아니다** — *신호 자체*가 비용 이전에 음의 기대값.
- → 이건 **B-3(체결 역선택)/비용 스토리가 아니다.** 체결을 아무리 잘 줘도(post_only≈maker) 신호에 양의 gross 엣지가 없다.

> 함의: 데이터를 확장해 n≥200을 채워도 gross_R 음수면 결론은 "엣지 없음"일 가능성이 높다. 단 규칙대로 *지금* 결론짓지 않는다.

## 2. 4-모드 비교 (B-6 확인 — 1d는 체결모델 수렴)

```
mode               n   win%    PF  grossR  costR   netR  3moMDD  Sharpe
post_only         86  30.2%  0.52  -0.242  0.015  -0.257   5.4%  -1.27
post_only_strict  57  28.1%  0.54  -0.242  0.015  -0.258   3.3%  -0.95
maker_open        86  29.1%  0.51  -0.242  0.024  -0.266   5.4%  -1.31
taker             86  29.1%  0.51  -0.242  0.026  -0.268   5.5%  -1.32
```
- post_only(86) ≈ maker_open(86): **1d에선 체결모델이 판정을 가르지 않는다**(B-6 결론 재확인). gross_R 동일(−0.242), cost_R만 미세 차이.
- post_only_strict(57): 시초가 갭 회피로 표본만 더 줄 뿐 엣지 부재 동일.
- 승률 ~30%는 **순수 트레일의 정상 프로파일**(저승률·우측꼬리). 판정은 승률이 아니라 PF·gross로 — 그 PF가 0.5대.

## 3. 왜 n=86까지 줄었나 (확률-최대화 필터의 비용)

6레버(롱전용 + BTC 200EMA risk-on + 거래량 동반 ×1.5 + mid-liq 동적 유니버스 + 순수 트레일 + post_only)가 **표본을 크게 깎았다**. 필터를 겹칠수록 "승률↑"을 노렸지만, 그 대가로 거래수가 판정 임계(200) 아래로 떨어졌고, **줄어든 표본에서도 gross 엣지가 양수로 돌아서지 않았다.** "확률을 올린다"는 설계가 *엣지를 만들지는 못했다.*

## 5. 한계 (반드시)

- **1d 테스트 — B-3(post_only 15초 역선택) 해소 아님.** B-3는 인트라데이 현상이라 일봉엔 안 나타남(§2 4모드 수렴이 그 증거). 정밀 체결은 B-8(testnet 실체결).
- 인트라데이(15m/1h/4h) 검증은 **데이터 백필 후 별도** — 본 결과를 인트라데이로 확대해석 금지.
- OOS 방식: 파라미터 사전확정·무최적화이므로 walk_forward 윈도우 재적합 불필요. 200EMA는 3mo 슬라이스에 워밍업 없어, **전체 1회 실행(워밍업 포함) → IS 12mo 이후를 OOS**로 partition(룩어헤드는 엔진이 차단).
